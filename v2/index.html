Methodology & Data Sources
  • PSI (24-hr): https://api.data.gov.sg/v1/environment/psi — National Environment Agency, via data.gov.sg. Official update cadence: every 15 minutes. Historical/nowcast values are pulled from this same endpoint's date-range query, not a separate archive.
  • PM2.5 (1-hr): https://api-open.data.gov.sg/v2/real-time/api/pm25 — National Environment Agency, via data.gov.sg. Official update cadence: hourly.
  • PSI bands: 0–100 Good to Moderate, 101–200 Unhealthy, 201–300 Very Unhealthy, 301+ Hazardous — per haze.gov.sg.
  • Personal Advisory shows haze.gov.sg's full official PM2.5 advisory table (all 4 bands × Healthy/Vulnerable persons), exact wording, not generated — v1 picked one profile from a dropdown mapped onto NEA's two tiers; v2 shows the whole table at once, with the row matching the current island-wide average PM2.5 highlighted.
  • "Average" figures (header, nowcast, range bars, trend charts) are a simple arithmetic mean of the 5 regional readings, computed in this page's own JS — not an NEA-published number.
  • Staleness: the header PSI figure's color dims subtly (hover for detail) if its reading timestamp is older than 2× NEA's real update cadence. [Certain, verified directly against consecutive live readings] NEA's psi_twenty_four_hourly figure actually updates on the hour, not every 15 minutes as the dataset's generic description states — an earlier version used the 15-minute figure and falsely flagged normal same-hour data as stale for up to 59 minutes of every hour. Fixed to the confirmed hourly cadence.
  • Map removed: an earlier version showed a region map. NEA publishes only one reference point per region (no finer geographic data is publicly available), so neither a smooth gradient nor a computed boundary shape could be made more accurate than a 5-region readout — it was dropped rather than presented as more precise than it is.
  • Header weather: relative humidity from api.data.gov.sg/v1/environment/relative-humidity (NEA), averaged over however many stations are currently reporting — coverage on this live endpoint varies and can be as low as 1 station at a given moment, shown as "N st" rather than implied as full-network. "Raining now" is a real-time measurement, not a forecast or probability — we checked both data.gov.sg and weather.gov.sg (MSS's own portal, same source organization) for a published rain probability and found none; this figure is instead the share of NEA's live rainfall stations (.../rainfall) currently reading above 0mm, out of however many are reporting right now, with a small gauge bar showing that percentage visually. Humidity and rain now fetch and render independently — a failure on one no longer blanks out the other.
  • "Min, Max, Range" (renamed from "Live Readings" in v1) shows the true low/high across ALL 5 regions over that period, not just the island-wide average — the 7-day PSI max, say, is whichever single region/hour had the highest reading, which may never show up in the average series at all. The min/max values sit directly above their tick mark on the scale, unitless for brevity (PM2.5's µg/m³ is implied, same as elsewhere on the page); hover a tick for the exact value, unit, and which region it came from. The pulsing dot on the track is the current island-wide average, for reference against that real spread. Scale is fixed (PSI 0–400, PM2.5 0–500), band-colored. No regional table is shown here; per-region readings live under each Nowcast headline instead.
  • PSI Forecast embeds NEA's own next-day forecast chart image directly from haze.gov.sg — not transcribed, not regenerated. haze.gov.sg has no JSON/API for this (checked their page source and scripts directly); it's published as a static image with a predictable date-based filename, which this page constructs for tomorrow's date each time it loads (re-checked hourly to catch the day rollover). If NEA ever changes the naming and the image fails to load, this falls back to a link to the live page rather than show a broken image.
  • Regional Map is a link-out, not an embed. We checked ASMC's (asmc.asean.org) homepage, hotspot page, and GIS portal source directly for a stable embeddable live map image or iframe and found none; the one candidate image we located (on their WIS 2.0 portal) returns HTTP 403 on direct fetch (hotlink-protected) and the page hosting it was last dated months before this was built, not live. Rather than embed something broken or stale, this links straight to ASMC's actual live interactive map.
  • 7-Day and 24-Hour Trend charts: both show PSI and PM2.5 as continuous lines, unsmoothed (each point is the exact observation, no curve-fitting between points). PSI is additionally shown with a shaded fill down to zero so its trend reads at a glance. Each chart's x-axis is a full fixed hourly grid for its declared window (168 points for 7 days, 24 for 1 day) built independently of what data actually arrived — a day or hour that failed to load is a visible gap in the line (not interpolated), and the axis always spans the complete window rather than shrinking to whatever arrived. The 7-day chart labels one tick per calendar day (same hour each time) instead of Chart.js's default auto-spaced ticks. The pulsing dot at the end of each line marks the latest actual observation plotted — a visual cue only, not a separate data point. [Likely] NEA's PM2.5 endpoint rate-limits bursts of unauthenticated requests on what tested as a flaky rolling window (inconsistent across repeated tests) — the oldest days in the 7-day window are the most likely to show a gap if it triggers, since days are fetched newest-first specifically so today's data is protected first; spacing between requests was widened to reduce how often this happens. The 24-hour window is anchored to the most recent actual reading, not to "today's calendar hours" — a fixed version briefly went almost empty right after midnight, since most of a brand-new day's hours are still in the future and have no data yet. The window, and the Live Readings 24h range bars and momentum trend below, now all roll correctly across the day boundary. The 24-hour chart's x-axis now labels every one of its 24 real hourly points (rotated for space) instead of Chart.js's default auto-skip to ~8 labels, which made the hourly data look sparser than it is — the line itself always plotted all 24 points regardless. History (both charts, range bars, momentum) now reloads every 15 minutes, not just once at page load — previously they froze at whatever was current when the page first opened, silently going stale while the rest of the page kept visibly refreshing.
  • Nowcast "Driven by X, not PM2.5" note: PSI is itself the max of 5 pollutant sub-indices (PM2.5, PM10, SO₂, CO, O₃) per NEA's own methodology. Normally PM2.5/smoke is what's driving an elevated PSI during haze, which isn't worth flagging — this note appears only when a different pollutant (e.g. ozone) is actually the highest sub-index, which the headline PSI number alone can't show. Hover it for the exact island-average sub-index values behind the call.
  • Momentum badge (top-right of Live Readings): mean island-wide average PSI over the last 24h vs the preceding 24h — a slow-moving, two-day-average comparison by design, so a single bad hour doesn't flip it. Any increase shows red (worsening), any decrease shows green (improving) — not banded into a "steady" dead zone.
  • Header "SG average PSI" trend arrow is a different, faster stat: the current hourly reading vs the one immediately before it (not a 24h average). PSI only updates once an hour at the source, so this is a genuine hour-over-hour comparison, not a polling artifact. Refreshed by its own lightweight check every 15 minutes (one small API call) independent of the full 7-day history reload, so it stays current without re-fetching everything. The header figure itself is the live current PSI reading, labeled "SG average" because it's the 5-region mean, not a single station — hover it for both numbers and the reading timestamps.
  • Nowcast is a pure view over the same live PSI/PM2.5 snapshot as the header and range bars — no fetch of its own. The 5 regions under each headline list vertically, worst first, each with a proportional mini-bar against the same fixed scale as the range bars above; a ⚠ appears when a region is more than 25 PSI points / 30 µg/m³ PM2.5 above the island average — a chosen threshold meant to surface a possible localized smoke plume early, not an NEA-defined alert. (An earlier version showed 1h/3h/24h trend deltas computed from an independent 7-day re-fetch; dropped in favor of the clearer region breakdown, which also cut 4 redundant API calls per page load.)
  • Wind panel: current direction/speed are a circular mean of NEA's live wind-direction/speed stations (.../wind-direction, .../wind-speed), converted from the API's native knots to km/h (×1.852). The two sentences (now, and a 3-day outlook) summarize NEA/MSS's own published .../4-day-weather-forecast API (first 3 of its 4 days), not a derived forecast — no row-by-row table, just the summary. Speed word (calm/light/moderate/strong) is a simplified, disclosed non-technical categorization, not an official wind scale. Direction is "where wind blows FROM"; a mention of carrying smoke toward Singapore appears only when a direction falls in the W–SW quadrant, the general direction of Sumatra fire activity — background context from general knowledge of regional haze patterns, not a verified source-attribution model. Exact degrees/knots are in the hover text. The temperature/humidity strip (🌡/💧 row) is a separate NEA source, .../24-hour-weather-forecast — a genuine next-24h forecast RANGE, not a live reading, distinct from the header's live current-humidity stat. The windmill icon is a decorative visual, not a separate measurement: its orientation reflects live wind direction (same convention as the arrow it replaces), and its spin rate is computed from the live speed as 24 / km/h seconds per rotation, clamped to 0.5–10s so it stays visible at both very calm and very windy readings — purely illustrative, hover it for the exact figures.
  • Methodology button moved from the header to the small ℯ icon, bottom-right of the page.
  • "Live feel" additions are presentation only, not new data: the "Xs/Xm ago" labels and the heartbeat dot (header, next to the clock) track when this page's own code last successfully completed a fetch to each API — the heartbeat turns stale-colored if no fetch anywhere has succeeded in 6 minutes. A value briefly flashes when it changes between refreshes. The browser tab title mirrors the current header PSI figure. The favicon is a triangle matching the same hourly trend as the header arrow — red pointing up when worsening, green pointing down when improving — so the direction is visible from another tab without opening it; before an hourly trend exists yet (e.g. just after page load) it falls back to a plain band-colored dot. The pulsing chart dots are covered above, under Trend charts.
  • If PM2.5 bars or chart lines appear empty: [Likely] NEA's PM2.5 endpoint (api-open.data.gov.sg) rate-limits unauthenticated request bursts more readily than the PSI endpoint does, observed directly during testing (HTTP 429 after ~6–7 rapid calls regardless of spacing). Removing Nowcast's own redundant fetch (see above) cut per-load PM2.5 calls from 10 to 8; requests also retry on 429 with backoff. If it still happens, it's a transient rate-limit window, not missing data at the source — NEA's API itself was confirmed working in every direct test run during this session.
  • No probabilistic forecast model (Monte Carlo baseline, backtest, Tier 2 commentary ingestion) has been built yet. Yahoo Weather AQI and IQAir data were investigated but not added — Yahoo's public API was retired in 2019 with no confirmed AQI field on its successor, and IQAir requires a user-created API key that would be exposed client-side on this static site.
