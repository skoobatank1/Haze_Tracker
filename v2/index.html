Methodology & Data Sources
  • PSI (24-hr): https://api.data.gov.sg/v1/environment/psi — National Environment Agency, via data.gov.sg. Official update cadence: every 15 minutes. Historical/nowcast values are pulled from this same endpoint's date-range query, not a separate archive.
  • PM2.5 (1-hr): https://api-open.data.gov.sg/v2/real-time/api/pm25 — National Environment Agency, via data.gov.sg. Official update cadence: hourly.
  • PSI bands: 0–100 Good to Moderate, 101–200 Unhealthy, 201–300 Very Unhealthy, 301+ Hazardous — per haze.gov.sg, used for color-coding throughout the page. The Personal Advisory table below uses NEA's own finer 5-way split for that specific table (Good 0–50 and Moderate 51–100 shown as separate rows, since NEA's advisory guide lists them separately even though both carry identical "Normal activities" guidance) — both are correct, just different granularities for different purposes.
  • Personal Advisory shows NEA's official 24-hour PSI health advisory table (from their "How to plan your outdoor activities during haze" guide, haze.gov.sg, PDF dated June 2026) — all 5 PSI bands × all 3 of NEA's distinct population groups (Healthy Persons; Elderly, Pregnant Women & Children; Persons with Chronic Lung Disease/Heart Disease), exact wording, not generated. This replaces an earlier version that used NEA's other table (the 1-hour PM2.5 guide), which only distinguishes "Healthy" vs a single merged "Vulnerable persons*" category — the PSI table is the one NEA actually breaks into 3 separately-worded groups. The highlighted row matches the current live 24-hr PSI reading, not a forecast: NEA's guide pairs this table with a next-day PSI forecast, but that forecast only exists as a published image with no API (see PSI Forecast below) — using today's already-fetched live PSI instead keeps the highlighted row real and verifiable rather than guessing at tomorrow's number.
  • "Average" figures (header, nowcast, range bars, trend charts) are a simple arithmetic mean of the 5 regional readings, computed in this page's own JS — not an NEA-published number.
  • Staleness: the header PSI figure's color dims subtly (hover for detail) if its reading timestamp is older than 2× NEA's real update cadence. [Certain, verified directly against consecutive live readings] NEA's psi_twenty_four_hourly figure actually updates on the hour, not every 15 minutes as the dataset's generic description states — an earlier version used the 15-minute figure and falsely flagged normal same-hour data as stale for up to 59 minutes of every hour. Fixed to the confirmed hourly cadence.
  • Map removed: an earlier version showed a region map. NEA publishes only one reference point per region (no finer geographic data is publicly available), so neither a smooth gradient nor a computed boundary shape could be made more accurate than a 5-region readout — it was dropped rather than presented as more precise than it is.
  • Header weather: relative humidity from api.data.gov.sg/v1/environment/relative-humidity (NEA), averaged over however many stations are currently reporting — coverage on this live endpoint varies and can be as low as 1 station at a given moment, shown as "N st" rather than implied as full-network. (A "raining now" stat — share of NEA's live rainfall stations reading above 0mm — was removed from the header.)
  • "PSI Min, Max, Range" shows the true low/high 24-hr PSI across ALL 5 regions over the last 24 hours and the last 7 days, not just the island-wide average — the 7-day max, say, is whichever single region/hour had the highest reading, which may never show up in the average series at all. PSI only (PM2.5 range rows were removed; PM2.5 is still in Nowcast and both trend charts). The min/max values sit directly above their tick mark; hover a tick for which region it came from. The pulsing dot on the track is the current island-wide average, for reference against that real spread. Scale is fixed (0–400), band-colored. "Last 7 days" is always the last 7 calendar days, independent of the trend chart's 7D/14D toggle.
  • PSI Forecast shows NEA's own published 24-hr PSI forecast gauge from haze.gov.sg — the forecast is a range (shaded wedge on the dial, printed in the pill, e.g. "101 – 190"), not a single figure. [Certain] haze.gov.sg has no JSON/API for this number; it only exists as pixels in that image, and the image itself carries no CORS header, so this page can't read its pixels either — redrawing it natively would mean guessing at the range, so NEA's actual image is shown whole and uncropped. haze.gov.sg's homepage HTML is CORS-open (access-control-allow-origin: *, verified), so the page fetches it and takes the exact image URL NEA is currently publishing rather than constructing a filename — a previous version guessed chart_<tomorrow>.png, but the real pattern is chart_1_<day>-<mon>.png dated the forecast day, so it failed every time. The "Advice:" band beside it is read from the filename of NEA's companion advisory image (e.g. unhealthy_19-oct.png); NEA's image states that advice "is based on the high end of the PSI forecast". If the homepage can't be read, the page falls back to today's expected filename, then to a link-out. Re-checked hourly.
  • Regional Map is a link-out, not an embed. We checked ASMC's (asmc.asean.org) homepage, hotspot page, and GIS portal source directly for a stable embeddable live map image or iframe and found none; the one candidate image we located (on their WIS 2.0 portal) returns HTTP 403 on direct fetch (hotlink-protected) and the page hosting it was last dated months before this was built, not live. Rather than embed something broken or stale, this links straight to ASMC's actual live interactive map.
  • Latest Headlines is news, not NEA/haze sensor data — included for local context, out of scope of this page's air-quality accuracy claims. Source: The Straits Times' own haze tag feed (straitstimes.com/tags/haze/rss.xml). [Certain, verified directly] That feed sends access-control-allow-origin: *, so it's fetched straight from the browser — no third-party proxy (an earlier version routed ST's general Singapore feed through rss2json.com and keyword-filtered it, which often surfaced only one haze item). The tag feed covers haze across the region (Malaysia, Indonesia), so it's narrowed to Singapore only: an item is kept if ST filed it under its /singapore/ section or its title names Singapore/S'pore. That's a rule over ST's own filing and titles, not manual curation — a Singapore-relevant story filed elsewhere without "Singapore" in its title will be missed rather than guessed at. Newest first; as many as fit the panel are shown. Titles and links are ST's own, not rewritten.
  • 7/14-Day and 24-Hour Trend charts: both show PSI and PM2.5 as continuous lines, unsmoothed (each point is the exact observation, no curve-fitting between points). PSI is additionally shown with a shaded fill down to zero. The long-range chart has a 7D / 14D toggle (7D default) — the same chart over a longer window, not a different calculation. Each chart's x-axis is a full fixed hourly grid for its window (168 or 336 points; 24 for the 24h chart) built independently of what data actually arrived — a day or hour that failed to load is a visible gap (not interpolated), and the axis always spans the complete window. The long-range chart labels one tick per calendar day. The pulsing dot at the end of each line marks the latest actual observation plotted — a visual cue only. Fetching: 14 days are loaded newest-first, and the default 7-day view renders as soon as its 7 days are in. Completed past days are cached after their first successful fetch (they don't change at the source), so the 15-minute history reload only re-fetches today and yesterday — the longer window costs extra NEA calls once per page load, not on every reload. [Likely] NEA's PM2.5 endpoint rate-limits bursts of unauthenticated requests on a flaky rolling window; the oldest days are the most likely to show a gap if it triggers, since days are fetched newest-first. The 24-hour window is anchored to the most recent actual reading, not to "today's calendar hours", so it rolls correctly across midnight; the range bars and momentum badge use the same anchoring.
  • Nowcast "Driven by X, not PM2.5" note: PSI is itself the max of 5 pollutant sub-indices (PM2.5, PM10, SO₂, CO, O₃) per NEA's own methodology. Normally PM2.5/smoke is what's driving an elevated PSI during haze, which isn't worth flagging — this note appears only when a different pollutant (e.g. ozone) is actually the highest sub-index, which the headline PSI number alone can't show. Hover it for the exact island-average sub-index values behind the call.
  • Momentum badge (top-right of Live Readings): mean island-wide average PSI over the last 24h vs the preceding 24h — a slow-moving, two-day-average comparison by design, so a single bad hour doesn't flip it. Any increase shows red (worsening), any decrease shows green (improving) — not banded into a "steady" dead zone.
  • Header PSI ticker replaces a single "SG average" figure with a scrolling strip of all 5 regions' live PSI (24-hr) readings, since the island-wide average already has its own place in the Nowcast panel below — this is meant to surface the regional spread at a glance instead. Hover the ticker to pause it and read a region's exact reading and timestamp. The small trend badge beside it is a different, faster stat: the current hourly reading vs the one immediately before it (not a 24h average) — PSI only updates once an hour at the source, so this is a genuine hour-over-hour comparison, not a polling artifact, refreshed by its own lightweight check every 15 minutes independent of the full 7-day history reload.
  • Nowcast is a pure view over the same live PSI/PM2.5 snapshot as the header and range bars — no fetch of its own. The 5 regions under each headline list vertically, worst first, each with a proportional mini-bar against the same fixed scale as the range bars above; a ⚠ appears when a region is more than 25 PSI points / 30 µg/m³ PM2.5 above the island average — a chosen threshold meant to surface a possible localized smoke plume early, not an NEA-defined alert. (An earlier version showed 1h/3h/24h trend deltas computed from an independent 7-day re-fetch; dropped in favor of the clearer region breakdown, which also cut 4 redundant API calls per page load.)
  • Wind panel: current direction/speed are a circular mean of NEA's live wind-direction/speed stations (.../wind-direction, .../wind-speed), converted from the API's native knots to km/h (×1.852). The two sentences (now, and a 3-day outlook) summarize NEA/MSS's own published .../4-day-weather-forecast API (first 3 of its 4 days), not a derived forecast — no row-by-row table, just the summary. Speed word (calm/light/moderate/strong) is a simplified, disclosed non-technical categorization, not an official wind scale. Direction is "where wind blows FROM"; a mention of carrying smoke toward Singapore appears only when a direction falls in the W–SW quadrant, the general direction of Sumatra fire activity — background context from general knowledge of regional haze patterns, not a verified source-attribution model. Exact degrees/knots are in the hover text. The temperature/humidity strip (🌡/💧 row) is a separate NEA source, .../24-hour-weather-forecast — a genuine next-24h forecast RANGE, not a live reading, distinct from the header's live current-humidity stat. The windmill icon is a decorative visual, not a separate measurement: its orientation reflects live wind direction (same convention as the arrow it replaces), and its spin rate is computed from the live speed as 24 / km/h seconds per rotation, clamped to 0.5–10s so it stays visible at both very calm and very windy readings — purely illustrative, hover it for the exact figures.
  • Methodology button moved from the header to the small ℯ icon, bottom-right of the page.
  • "Live feel" additions are presentation only, not new data: the "Xs/Xm ago" labels and the heartbeat dot (header, next to the clock) track when this page's own code last successfully completed a fetch to each API — the heartbeat turns stale-colored if no fetch anywhere has succeeded in 6 minutes. A value briefly flashes when it changes between refreshes. The browser tab title mirrors the current header PSI figure. The favicon is a triangle matching the same hourly trend as the header arrow — red pointing up when worsening, green pointing down when improving — so the direction is visible from another tab without opening it; before an hourly trend exists yet (e.g. just after page load) it falls back to a plain band-colored dot. The pulsing chart dots are covered above, under Trend charts.
  • If PM2.5 bars or chart lines appear empty: [Likely] NEA's PM2.5 endpoint (api-open.data.gov.sg) rate-limits unauthenticated request bursts more readily than the PSI endpoint does, observed directly during testing (HTTP 429 after ~6–7 rapid calls regardless of spacing). Removing Nowcast's own redundant fetch (see above) cut per-load PM2.5 calls from 10 to 8; requests also retry on 429 with backoff. If it still happens, it's a transient rate-limit window, not missing data at the source — NEA's API itself was confirmed working in every direct test run during this session.
  • No probabilistic forecast model (Monte Carlo baseline, backtest, Tier 2 commentary ingestion) has been built yet. Yahoo Weather AQI and IQAir data were investigated but not added — Yahoo's public API was retired in 2019 with no confirmed AQI field on its successor, and IQAir requires a user-created API key that would be exposed client-side on this static site.
