Methodology & Data Sources
  • PSI (24-hr): https://api.data.gov.sg/v1/environment/psi — National Environment Agency, via data.gov.sg. Official update cadence: every 15 minutes. Historical/nowcast values are pulled from this same endpoint's date-range query, not a separate archive.
  • PM2.5 (1-hr): https://api-open.data.gov.sg/v2/real-time/api/pm25 — National Environment Agency, via data.gov.sg. Official update cadence: hourly.
  • PSI bands: 0–100 Good to Moderate, 101–200 Unhealthy, 201–300 Very Unhealthy, 301+ Hazardous — per haze.gov.sg.
  • PM2.5 bands & advisory text: the exact Healthy-person / Vulnerable-person advisory wording in the Personal Advisory panel is copied from haze.gov.sg's own PM2.5 table, not generated. Profiles map to NEA's two published tiers: "General/healthy adult" and "Outdoor worker/exerciser" use the Healthy-person column (with an added note on exertion); Elderly, Pregnant, Young child, and Asthma/chronic condition use the Vulnerable-person column.
  • "Average" figures (header, nowcast, range bars, trend charts) are a simple arithmetic mean of the 5 regional readings, computed in this page's own JS — not an NEA-published number.
  • Staleness: the header PSI figure's color dims subtly (hover for detail) if its reading timestamp is older than 2× NEA's real update cadence. [Certain, verified directly against consecutive live readings] NEA's psi_twenty_four_hourly figure actually updates on the hour, not every 15 minutes as the dataset's generic description states — an earlier version used the 15-minute figure and falsely flagged normal same-hour data as stale for up to 59 minutes of every hour. Fixed to the confirmed hourly cadence.
  • Map removed: an earlier version showed a region map. NEA publishes only one reference point per region (no finer geographic data is publicly available), so neither a smooth gradient nor a computed boundary shape could be made more accurate than a 5-region readout — it was dropped rather than presented as more precise than it is.
  • Header weather: relative humidity from api.data.gov.sg/v1/environment/relative-humidity (NEA), averaged over however many stations are currently reporting — coverage on this live endpoint varies and can be as low as 1 station at a given moment, shown as "N st" rather than implied as full-network. "Raining now" is a real-time measurement, not a forecast or probability — we checked both data.gov.sg and weather.gov.sg (MSS's own portal, same source organization) for a published rain probability and found none; this figure is instead the share of NEA's live rainfall stations (.../rainfall) currently reading above 0mm, out of however many are reporting right now.
  • Live Readings range bars (Last 24 Hours / Last 7 Days subsections) show the low/high of the island-wide average against a fixed band-colored scale (PSI 0–400, PM2.5 0–500), with a marker for the current reading — computed from the same hourly series as the trend charts below. No regional table is shown here any more; per-region readings now live under each Nowcast headline instead.
  • 7-Day and 24-Hour Trend charts: both show PSI and PM2.5 as continuous lines, unsmoothed (each point is the exact observation, no curve-fitting between points). PSI is additionally shown with a shaded fill down to zero so its trend reads at a glance. Each chart's x-axis is a full fixed hourly grid for its declared window (168 points for 7 days, 24 for 1 day) built independently of what data actually arrived — a day or hour that failed to load is a visible gap in the line (not interpolated), and the axis always spans the complete window rather than shrinking to whatever arrived. The 7-day chart labels one tick per calendar day (same hour each time) instead of Chart.js's default auto-spaced ticks. The pulsing dot at the end of each line marks the latest actual observation plotted — a visual cue only, not a separate data point.
  • Momentum badge (top-right of Live Readings) and the header-center PSI figure's trend arrow use the same underlying number: mean island-wide average PSI over the last 24h vs the preceding 24h. Any increase shows red (worsening), any decrease shows green (improving) — not banded into a "steady" dead zone. The header figure itself is the live current PSI reading (not the 24h mean) — hover it for both numbers and the reading timestamp.
  • Nowcast is a pure view over the same live PSI/PM2.5 snapshot as the header and range bars — no fetch of its own. The 5 region cells under each headline are the current live regional readings; a ⚠ appears when a region is more than 25 PSI points / 30 µg/m³ PM2.5 above the island average — a chosen threshold meant to surface a possible localized smoke plume early, not an NEA-defined alert. (An earlier version showed 1h/3h/24h trend deltas computed from an independent 7-day re-fetch; dropped in favor of the clearer region breakdown, which also cut 4 redundant API calls per page load.)
  • Nowcast "24h ago": compares the current hourly reading to the same hour yesterday, using the same NEA date-range query as the trend charts. Rising vs. falling is shown by the color/arrow on each 1h/3h/24h delta box (red up, green down).
  • Wind panel: current direction/speed are a circular mean of NEA's live wind-direction/speed stations (.../wind-direction, .../wind-speed), converted from the API's native knots to km/h (×1.852). The two sentences (now, and a 3-day outlook) summarize NEA/MSS's own published .../4-day-weather-forecast API (first 3 of its 4 days), not a derived forecast — no row-by-row table, just the summary. Speed word (calm/light/moderate/strong) is a simplified, disclosed non-technical categorization, not an official wind scale. Direction is "where wind blows FROM"; a mention of carrying smoke toward Singapore appears only when a direction falls in the W–SW quadrant, the general direction of Sumatra fire activity — background context from general knowledge of regional haze patterns, not a verified source-attribution model. Exact degrees/knots are in the hover text.
  • Methodology button moved from the header to the small ℯ icon, bottom-right of the page.
  • "Live feel" additions are presentation only, not new data: the "Xs/Xm ago" labels and the heartbeat dot (header, next to the clock) track when this page's own code last successfully completed a fetch to each API — the heartbeat turns stale-colored if no fetch anywhere has succeeded in 6 minutes. A value briefly flashes when it changes between refreshes. The browser tab title and favicon mirror the current header PSI figure and its band color so the reading stays visible from another tab. The pulsing chart dots are covered above, under Trend charts.
  • If PM2.5 bars or chart lines appear empty: [Likely] NEA's PM2.5 endpoint (api-open.data.gov.sg) rate-limits unauthenticated request bursts more readily than the PSI endpoint does, observed directly during testing (HTTP 429 after ~6–7 rapid calls regardless of spacing). Removing Nowcast's own redundant fetch (see above) cut per-load PM2.5 calls from 10 to 8; requests also retry on 429 with backoff. If it still happens, it's a transient rate-limit window, not missing data at the source — NEA's API itself was confirmed working in every direct test run during this session.
  • No probabilistic forecast model (Monte Carlo baseline, backtest, Tier 2 commentary ingestion) has been built yet. Yahoo Weather AQI and IQAir data were investigated but not added — Yahoo's public API was retired in 2019 with no confirmed AQI field on its successor, and IQAir requires a user-created API key that would be exposed client-side on this static site.
